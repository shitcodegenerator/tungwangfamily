# 手動測試流程（Phase 1～4）

自動化測試（`validate_map.py`、`run_tests.gd`、`--route-test`）已涵蓋「能不能走、能不能互動、碰撞有沒有壞」。
這份流程專門檢查自動化測不出來的東西：手感、節奏、視覺、聲音（目前無）。全程約 40 分鐘。

啟動：

```bash
godot --path /Users/dongyixuan/tungworld
```

視窗 1280×720（邏輯解析度 640×360，2 倍放大）。按 Esc 可隨時開啟操作說明面板。

每一節請在「結果」欄填 ✅／❌，❌ 請寫下發生什麼、在哪個位置（HUD 狀態列會顯示座標與格）。
