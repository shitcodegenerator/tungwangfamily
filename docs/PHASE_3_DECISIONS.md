# Phase 3 已確認決策

這份文件是 Phase 3 的內容邊界與設計決策。若本文件與早期需求文件衝突，以本文件為準。

## 已確認

- 任務入口採「任務引導」：玩家有清楚的目前目標，但可以離開路線自由探索中央小鎮。
- 室內場景採「少量開放」：第一批只做兩個室內場景。
- 媽媽與乾媽住在同一間共享家庭屋。兩人的生活區、工作區和孩子們的公共空間放在同一個場景中。
- 父親原型 NPC 使用「國王企鵝船長」，不是海獺漁夫。
- Phase 3 不定義正式章節劇情、不定義 Boss、不決定父親被帶走的演出內容。
- Phase 3 可以使用中性的技術測試任務，但所有測試文字必須標記為 `TEMP_DEMO_CONTENT`，不可當成正式世界觀。

## 室內場景

### 共享家庭屋

這是媽媽、乾媽與四個孩子共同生活的家。第一版建議包含：

- 入口與回到樹洞城的出口點
- 中央共用餐桌
- 廚房與食材互動點
- 縫紉工作區
- 孩子們的遊戲／雜物角
- 一個可替換的「家庭記憶物件」互動點

最後一項只做系統插槽，不放入真實回憶文字，等待作者提供內容。

### 船長房間

這是國王企鵝船長的私人房間，連接港口職能，但不直接揭露正式主線真相。第一版建議包含：

- 航海圖桌
- 船具與釣具展示點
- 舷窗或潮汐觀測點
- 可替換的「船長重要物件」互動點

重要物件只提供互動介面與空白資料欄位；正式內容需要先詢問作者。

## 本階段刻意不做

- Boss 與重要戰鬥
- 父親離世事件的正式演出
- 乾媽家庭傷痛的描寫
- 寵物養成與戰鬥
- 複雜對話分支
- 多結局

## 命名規則

- 角色顯示名稱可以使用世界觀內的稱號，例如「國王企鵝船長」。不要在程式碼中使用真實親屬稱謂。
- `family_home` 表示共享家庭屋；不要拆成 `mother_house` 與 `godmother_house`。
- 所有測試任務、測試對話和測試互動物件使用 `demo_` 或 `TEMP_DEMO_CONTENT` 前綴。
