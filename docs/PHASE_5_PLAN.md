# Phase 5：每日循環與主城地圖美術垂直切片

## 本階段目標

Phase 4.6 已完成角色動畫、陰影、隊伍分離、正式洞窟 tile 和 Boss 邊界。Phase 5 不直接擴張大型劇情，而是完成一個可重複使用的遊戲日循環，並把主城其中一個區域改成新的 modular 美術。

### 5A：每日系統

- GameState 升級到 schema v3，新增 day、day_seed、daily_state。
- 從共享家庭屋的休息點／床休息，確認後進入下一天。
- 回到主城或家庭屋時依存檔狀態復原，不因切場景重複增加天數。
- 每日重置採明確的 reset_daily_state() hook，先不把所有任務硬編碼進核心。
- day_seed 讓每日掉落、裝飾或隨機事件可重現，之後可以替換成日期種子。
- 初版只做早晨→白天→傍晚的簡單轉場；不建立複雜時鐘，也不新增尚未確認的劇情。

### 5B：主城下層樹根廣場垂直切片

先替換共享家庭屋、阿嬤早餐攤與中央廣場附近的視覺，不一次重畫全部主城。地圖的 ASCII、碰撞和出口資料先維持不變，只替換視覺 atlas 與 props。

- 使用 town_visual_refresh_tiles_32.png 作為新地面 atlas。
- 使用 assets/props/town_refresh/ 的八個物件做第一批替換。
- 先完成草地、石板路、水岸、木橋、樹根牆五種材質的鄰接測試。
- 地圖裝飾與碰撞分離，所有大型物件的碰撞仍由 JSON／Area2D 定義。
- 第一個垂直切片完成後才決定是否將新 atlas 全面套用到上層樹冠與港口。

## 本階段不做

- 不新增第二個 Boss 或新的主線劇情。
- 不把 CC 的日常餵食規則自行定案；那需要作者確認每日食物、好感度和獎勵。
- 不刪除舊 atlas、舊 props 或舊存檔欄位；所有替換都保留可回退版本。

## 建議完成順序

1. 先完成 schema v3 遷移與 F6/F7 測試。
2. 接上家庭屋休息點：確認→日數 +1→保存→早晨轉場。
3. 新增每日 reset hook，但只接一個示範旗標，驗證重置時機。
4. 替換下層樹根廣場的地面 tile，不動碰撞。
5. 替換共享家庭屋外觀、早餐攤、燈籠和心形噴泉。
6. 做夜晚／清晨色調與截圖驗收。

## 驗收條件

- 新遊戲從 day 1 開始；讀取 v2 存檔不崩潰且補上 v3 預設值。
- 只有在共享家庭屋休息確認後才會進入下一天；取消不增加 day。
- 連續切換場景不會重複增加 day；重啟後 day、旗標、位置和任務一致。
- 每日 reset hook 只執行一次，且不清掉永久旗標與 CC 加入狀態。
- 下層廣場視覺不再使用大面積單一重複石板；草地、石板、水岸與木橋的過渡沒有白邊。
- 大型 props 的底部接地、Y-sort 和碰撞都正確；角色可從出口與屋門正常通行。
- Phase 1～4.6 的 177 個單元測試、210 個 route test，以及新增 Phase 5 測試全部通過。
