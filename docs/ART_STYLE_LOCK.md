# tungwangfamily 美術一致性鎖定表

這份文件是之後產出或替換任何角色、NPC、寵物、物件與地圖素材前的硬性檢查表。
目的不是限制創意，而是讓同一個角色在行走、待機、持物、對話與戰鬥時仍然像同一個角色。

## 1. 專案基準

| 項目 | 固定規格 |
|---|---|
| 引擎 | Godot 4.7.x |
| 主畫面 | 640×360 邏輯畫面 |
| 像素倍率 | 整數倍率 |
| Filter | Nearest |
| Tile | 32×32 |
| 主角行走格 | 48×64 |
| 主角每格腳底 | y=61，底部保留約 2px |
| 主角行走列序 | down／left／right／up，以實際臉朝向確認 |
| 角色陰影 | 使用現有 character_shadow.png；錨點固定在腳底 |
| 寵物陰影 | 使用現有 pet_shadow.png；錨點固定在腳底 |
| 光源方向 | 場景內固定，不因單張素材自行改變 |

## 2. 四位主角造型鎖

新增素材不能改變以下識別特徵：

- 哥哥：紅鬃山犬、較寬體格、紅色圍巾、領袖感。
- 冷靜哥：灰藍色貓頭鷹、圓眼鏡、小書袋、冷靜表情。
- 弟弟：溪水猴、藍色系、長手長腳、活潑姿勢。
- 妹妹：胖胖自然捲綿羊、圓潤身形、食物斜背袋。

如果未來要改造型，必須同時提供：

1. 行走表。
2. 待機表。
3. 持物／投擲表。
4. 頭像。
5. 對照圖：舊版與新版並排。

不能只替換其中一張，否則角色切換動作時會突然變形。

## 3. 新素材的製作流程

### 3.1 先鎖定參考

產圖或手繪前，先指定：

- 角色 ID。
- 目前正式 sprite 的路徑。
- 畫布大小。
- 腳底線。
- 列序與欄序。
- 是否需要陰影。
- 是否允許新增服裝或配件。

不得只寫「畫一個類似原本的角色」。

### 3.2 先做單幀，再做動畫

順序固定為：

    站立幀確認
    → 四方向站立確認
    → 行走幀
    → 待機幀
    → 持物／投擲幀
    → 頭像

站立幀沒有通過，就不能繼續生成動畫。

### 3.3 像素檢查

- 不使用非整數縮放。
- 不使用模糊抗鋸齒。
- 不使用自動補邊造成的白線。
- 背景必須是真透明，不是白色或棋盤格。
- 角色腳底不能每幀上下漂移。
- 待機動畫只能移動身體視覺，不可移動碰撞盒、陰影或地面錨點。

## 4. 地圖與物件一致性

地圖固定拆成：

    Ground TileMap
    → Wall／Root TileMap
    → Props layer
    → Collision layer
    → Interactable layer
    → Foreground／Y-sort layer

大型物件必須：

- 以底部中央作為 origin。
- 需要偏移時使用 foot_x 或 foot_inset。
- 圖片、碰撞和互動區分開。
- 不把角色陰影畫進物件 PNG。
- 不把整張地圖畫成一張不可拆的背景。

## 5. Shader 一致性

Shader 只用於環境氣氛：

- 水面反光。
- 舷窗水光。
- 燈光脈動。
- 雲霧或少量環境流動。

Shader 不得改變：

- 角色身形。
- 角色腳底位置。
- 角色陰影。
- 碰撞。
- 互動範圍。

每個 Shader 都要有低強度預設值，關閉 Shader 時場景仍然可以遊玩。

## 6. 交付前檢查

### 圖片

    file asset.png
    → 確認 PNG／RGBA
    → 確認尺寸
    → 檢查透明背景
    → 3 倍放大查看腳底、邊緣與白線

### 遊戲

    godot --headless --path . --import
    python3 tools/validate_map.py
    godot --headless --path . -s res://tests/run_tests.gd
    route test

### 人工截圖

- 角色停止時陰影仍在腳底。
- 角色走路時陰影不漂移。
- 角色持物時沒有滑行。
- 角色切換時身高與頭部位置一致。
- 大型物件沒有漂浮。
- 物件沒有遮住必要出口。
- Tile 沒有白線或格框。

## 7. 明確禁止

- 未經作者確認重新生成四位主角。
- 用不同畫風的 NPC 直接塞進既有場景。
- 用整張 AI 生成背景取代 TileMap。
- 把暫時 placeholder 當成正式劇情。
- 把家庭傷痛或真實回憶自行寫入劇情。
- 把 CC 的台詞寫成長段落；CC 維持短句並以「です」結尾。
