# Phase 3：任務引導、NPC、少量室內與存檔

## 目標

把目前可自由走動的中央小鎮，擴展成一個可反覆遊玩的「小型垂直切片」：玩家能接到任務、與 NPC 對話、進入共享家庭屋和船長房間、完成一個中性的測試任務，並在存檔後恢復進度。

這一階段先建立可擴充的骨架，不替作者寫正式回憶劇情。後續正式章節只需要替換 JSON、旗標和事件資料，不應該重寫場景核心。

## 玩家體驗範圍

1. 玩家在中央小鎮自由探索。
2. 公告欄或指定 NPC 提供目前任務。
3. 任務日誌顯示一個主目標與目前進度。
4. 玩家可以進入共享家庭屋，與中性互動點互動後離開。
5. 玩家可以進入船長房間，與國王企鵝船長及市集老龜對話。
6. 完成測試任務後，任務狀態和旗標可以保存並在讀檔後恢復。

任務不應把玩家硬鎖在單一路線；任務只是提供方向。小鎮原有出口、日夜切換、角色切換和跟隨隊伍都要保留。

## 建議實作順序

### 3.1 建立單一遊戲狀態

新增可被各系統讀寫的 `GameState`，至少包含：

- `schema_version`
- `current_scene_id`
- `return_scene_id` 與 `return_position`
- 四位角色的目前隊伍順序與位置
- `time_of_day`
- `flags: Dictionary`
- `quests: Dictionary`
- 已開放室內場景清單

旗標和任務狀態必須集中管理，不要分散在公告欄、NPC 和場景腳本的各自變數中。

### 3.2 存檔與讀檔

- 路徑：`user://save_01.json`
- 格式：UTF-8 JSON
- 存檔資料帶版本號，為日後欄位遷移保留空間
- 優先保存：場景、玩家位置、隊伍順序、日夜、旗標、任務狀態
- 讀檔失敗時保留目前遊戲狀態並顯示可理解的錯誤，不要讓遊戲直接崩潰
- 第一版可提供 debug 快捷鍵，例如 `F6` 儲存、`F7` 讀取；不得與既有 `F1`、`F5`、`Esc` 衝突

### 3.3 場景轉換

建立簡單的 `SceneRouter` 或等價服務：

- 戶外小鎮 → `family_home`
- `family_home` → 回到進入前的小鎮位置
- 戶外小鎮 → `captain_room`
- `captain_room` → 回到港口附近的固定安全位置

第一版不需要房屋內再分多個房間。場景轉換時要暫停玩家輸入、完成淡入淡出，再恢復輸入。

### 3.4 NPC 與對話

加入兩位可互動 NPC：

- 國王企鵝船長：父親原型的世界觀化角色，先提供職能和日常對話插槽
- 市集老龜：提供市集方向、物品或任務系統測試用的中性 NPC

兩位 NPC 第一版只需要站立／待機、碰撞、互動提示、對話和頭像，不需要巡邏或戰鬥。

對話資料必須支援：

- `id`
- `speaker_id`
- `text`
- `portrait_id`
- `requires`：旗標或任務狀態條件
- `on_complete`：設置旗標、更新任務、開放場景等動作

先做一層簡單條件判斷即可，不要在本階段做複雜分支樹。

### 3.5 任務系統

任務資料建議使用 JSON，欄位保留：

```json
{
  "id": "demo_town_orientation",
  "title": "TEMP_DEMO_CONTENT",
  "state": "available",
  "objectives": [
    {"id": "read_notice", "kind": "interact", "target": "bulletin_board", "count": 1}
  ],
  "rewards": {"flags": ["demo_orientation_complete"]},
  "visibility": "main"
}
```

必要狀態先做 `available`、`active`、`completed`。保留 `failed` 欄位的相容性，但本階段不要設計失敗條件。

測試任務可以要求玩家：查看公告欄、進入共享家庭屋、查看船長房間的一個中性互動點，再回報任務。任務文字要明確標記為測試內容，日後由作者提供正式內容後替換。

### 3.6 任務 UI

- HUD 顯示目前主目標的一行摘要
- 可用 `Tab` 或既有選單入口開啟最小任務清單
- 任務完成時顯示短暫提示
- 對話中、場景轉換中、Esc 面板開啟時，任務 UI 不應搶輸入

## 可擴充性要求

- 場景使用穩定的 `scene_id`，不要用節點路徑當存檔 ID。
- 任務與對話使用資料檔，條件與完成動作集中在可測試的服務。
- 室內場景以「入口／出口／互動點」標準介面製作，之後可增加老家、雲端天塔或海底洞窟。
- 角色、NPC、寵物日後都能共用互動提示與對話介面。
- 所有新增內容都必須保留 Phase 1／2 的四人切換、跟隨、日夜和碰撞功能。

## 驗收條件

- 能從乾淨啟動進入中央小鎮，不破壞既有 40 項手動測試。
- 公告欄能啟動測試任務，任務摘要能更新。
- 能進出共享家庭屋，返回位置合理且隊伍仍存在。
- 能進出船長房間，國王企鵝船長和老龜可以互動。
- `F6` 存檔、重新啟動、`F7` 讀檔後，場景、位置、日夜、旗標和任務狀態一致。
- 對話中不能移動、切換角色或讓跟隨隊伍失控。
- 沒有新增正式劇情、Boss 或作者未確認的私人回憶。
