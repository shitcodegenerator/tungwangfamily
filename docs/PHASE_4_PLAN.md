# Phase 4：CC 與炸物魔王戰鬥切片

## 目標

在 Phase 3 穩定版上加入第一個具有完整遊戲循環的內容切片：玩家向阿嬤取得香椿乾拌麵，交給早餐攤旁的 CC，進入一次性的炸物魔王洞窟，使用撿取與投擲完成低壓戰鬥，回到 CC 身邊後讓 CC 加入非戰鬥寵物系統。

本階段不做正式家庭回憶、不做沉重背景、不做複雜 RPG 戰鬥框架。炸物魔王是純幻想、一次性、搞笑型教學 Boss。

## 已定案內容

- CC 位於阿嬤早餐攤旁。
- 原本「收集三種食物」任務取消。
- 香椿乾拌麵是必要任務物品，不是替代方案。
- 香椿乾拌麵與炸物魔王都必須完成。
- CC 留在早餐攤旁，負責傳送玩家。
- 炸物魔王洞窟只出現一次。
- 炸物魔王是戴王冠的炸全雞，行為白癡搞笑。
- 青菜、綠茶、水初版造成相同傷害。
- Boss 被命中 5 次後倒下。
- 每次命中掉落一隻炸雞翅；炸雞翅落地後消失，只作為命中回饋。
- Boss 攻擊保留低傷害。
- 主角受傷先使用短暫變色與閃爍，不新增受傷 Sprite。
- 戰鬥失敗回到 CC 旁，再次傳送重新開始。
- 戰鬥勝利回到 CC 旁，進入 CC 加入橋段。
- 玩家切換成弟弟時，弟弟的移動速度固定較快。
- CC 加入後跟在四人隊伍最後，偶爾做小動作，不參與戰鬥。

## 任務流程

```text
找到 CC
  → 取得香椿乾拌麵
  → 將香椿乾拌麵交給 CC
  → CC 傳送至炸物魔王洞窟
  → 撿取青菜／綠茶／水
  → 舉起物品並投擲
  → Boss 被命中 5 次
  → 返回 CC 旁
  → 接受／拒絕 CC 加入
  → CC 強制加入
```

## 建議狀態旗標

```text
cc_found
cc_noodle_delivered
cc_cave_active
cc_fried_food_demon_defeated
cc_joined
cc_join_choice
cc_rejection_reaction_seen
```

失敗時清除本次戰鬥暫態資料，但不要清除 `cc_noodle_delivered`。玩家已經取得的香椿乾拌麵不應因戰鬥失敗而消失。

## 戰鬥設計

### 戰鬥控制

- 仍然使用即時移動。
- 只有目前操控角色可以撿取、舉起與投擲。
- 四位角色都必須能使用同一套撿取／舉物／投擲流程。
- 跟隨者不自動撿取，不自動投擲。
- `E` 優先處理互動、撿取和投擲；對話和轉場期間鎖定移動。

### 投擲物

- `vegetable_bundle`
- `green_tea`
- `water_flask`

初版三種物品的傷害完全相同。保留 `effect_type` 欄位供日後加入屬性，但第一版全部使用 `plain_damage`。

### Boss

建議先使用 5 點生命值，每次有效命中扣 1 點。Boss 只需要簡單狀態：待機、移動、攻擊預兆、攻擊、受擊、倒地。

Boss 攻擊必須有明顯預兆且傷害低。受傷先套用角色 `modulate` 變色、短暫閃爍與無敵時間，不等待正式受傷圖片。

### 命中回饋

每次命中依序執行：

1. Boss 受擊閃白／抖動。
2. 一隻炸雞翅從 Boss 身上掉下來。
3. 炸雞翅彈跳一次。
4. 炸雞翅淡出或縮小消失。
5. Boss 生命值減 1。

第五次命中後才進入倒地和勝利流程。

## 素材使用原則

- `assets/reference/incoming/` 內素材是本階段方向參考和切割來源，不得直接覆蓋既有正式資源。
- 角色行動表以目前專案 48×64 格為目標。
- 物品是獨立 Sprite，掛到角色的 `CarryAnchor`，不要把物品畫死在角色 Sprite 裡。
- 洞窟圖片是布局參考，請用 32×32 tiles 重建可走、可碰撞的場景。
- Boss 與角色素材需經過尺寸、透明邊界、接地線和 Nearest filtering 驗證。

## Phase Gate

### 4A 通過條件

- 香椿乾拌麵可取得並交給 CC。
- CC 可傳送玩家，且失敗時能回到 CC 旁。
- 任務和傳送狀態可存檔。

### 4B 通過條件

- 三種物品能撿起、舉起、投擲。
- 四位角色都能使用。
- 投擲物能正確命中 Boss。

### 4C 通過條件

- Boss 5 次命中後倒下。
- 每次命中掉一隻炸雞翅並消失。
- 玩家受傷以變色表示。
- 戰鬥失敗可重新傳送，不會卡在洞窟。

### 4D 通過條件

- CC 加入選項可完成。
- 拒絕時顯示 `💢` 與 OS「你怎麼忍心!!!」。
- CC 跟在四人隊伍最後。
- 既有 Phase 1～3 測試不退化。
