# 圖片素材需求清單（交給 AI 產圖用）

所有素材共通規格：

- 像素風（pixel art），畫面色調與 `assets/reference/phase1_tide_root_town_reference.png` 一致：
  暖木色、苔綠、樹皮深棕、琥珀燈光、藍綠色水面。
- **透明背景 PNG**，不要漸層背景、不要投影、不要浮水印。
- 圖片內每個物件請以**清楚的透明間隔**分開（間隔至少 16px），我會用透明區域自動切割。
- 不要使用任何既有遊戲的角色或商標。
- 產圖尺寸若無法剛好符合，請維持**整數倍**（例如 2×、4×），我會等比例縮回，不要非整數縮放。

優先級：**A = Phase 1 立即替換 placeholder**，**B = Phase 2 需要**，**C = Phase 3 以後**。


四位角色高度請一致（約 56px），弟弟可以略矮一點但不要低於 46px。
