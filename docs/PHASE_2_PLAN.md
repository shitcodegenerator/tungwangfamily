# Phase 2：互動與城鎮生命

## 主要目標

讓 Phase 1 的可走地圖開始變成一個有回應的城鎮。玩家本階段可以靠近物件、按下互動鍵、看到對話與提示，並感受到樹洞城不是靜止背景。

## 本階段完成範圍

### 1. 互動基礎

- 接上角色已預留的 `InteractionArea`。
- 使用 `interact` 輸入鍵，預設為 E。
- 偵測玩家前方或附近的可互動物件。
- 同時有多個物件時，選擇距離最近者。
- 顯示目前可互動物件的提示圖示。
- 互動完成後發送 signal，不把對話邏輯寫死在角色腳本。

### 2. 對話框元件

- 木框與羊皮紙底。
- 顯示角色名稱與對話內容。
- 支援逐字顯示。
- 按 E 顯示下一句。
- 對話時暫停角色移動，但不破壞地圖與隊伍位置。
- 預留未來頭像與選項接口。

Phase 2 只做單線對話，不做任務條件、分支選項與存檔條件。

### 3. 三種互動物件

| 物件 | 行為 |
|---|---|
| 公告欄 | 顯示一段城鎮公告 |
| 樹心 | 顯示一段含蓄神秘的文字 |
| 未開放出口 | 顯示區域尚未開放提示 |

### 4. 城鎮生命動畫

- 燈籠 4 幀閃爍。
- 水面 4 幀循環。
- 樹葉、螢火蟲或蝴蝶出現與消失。
- 旗幟輕微擺動。
- 雲霧緩慢位移。

動畫是低成本視覺效果，不應影響碰撞與遊戲邏輯。

### 5. 日夜狀態最小版本

先不加入時間管理系統，只提供 Debug 按鍵切換 Day、Dusk、Night。使用 `CanvasModulate` 或環境色調控制，不要重新繪製三份地圖。

## 不包含項目

- 戰鬥、小怪、經驗值、等級、裝備、技能。
- 寵物、背包、送禮、任務追蹤。
- 房屋內部與父親原型的正式第一章劇情。

## 建議執行順序

1. 建立 Interactable 基底介面與公告欄測試。
2. 接上 E 鍵、最近目標選擇與互動提示。
3. 建立可重複使用的對話框場景。
4. 將公告欄、樹心、出口接上對話框。
5. 加入燈籠、水面、旗幟與雲霧動畫。
6. 加入 Debug 日夜切換。
7. 執行互動、隊伍、鏡頭與碰撞回歸測試。

## 驗收結果

玩家可以在主城中自由走動、與公告欄和樹心互動、查看三個封鎖出口提示，並看到燈籠、水面、旗幟與雲霧循環動畫。日夜切換不改變地圖碰撞；對話前後切換角色，隊伍仍然完整且不傳送。
